# AutoAH - Fabric Mod for Minecraft 1.21

Automated auction house mod for DonutSMP.

## Features

- Automatically opens `/ah chest` command
- Buys 64 wood chests (price range: 30k-60k)
- Places chests in double chest one at a time
- Fills hotbar with single chests (one per slot)
- Automatically runs `/ah sell 5000`
- Shows confirmation popup with clickable green glass pane

## Usage

1. Stand in front of a double chest
2. Run `/autoah toggle on` to start automation
3. Click the green glass pane to confirm sales
4. Run `/autoah toggle off` to disable

## Commands

- `/autoah toggle on` - Enable automation
- `/autoah toggle off` - Disable automation
- `/autoah sell chest` - Set sellable item to chest (5000 coins)
- `/autoah sell furnace` - Set sellable item to furnace (5000 coins)
- `/autoah sell hopper` - Set sellable item to hopper (6000 coins)
